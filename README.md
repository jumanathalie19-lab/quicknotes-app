# QuickNotes
QuickNotes is a simple note-taking web app to capture ideas before they disappear. Built for PLP Web Development Foundations.

## Features
- Add notes with category (personal, work, ideas)
- Live character (0 / 200) and word counter with warning
- Validation for empty and >200 chars
- Search notes, delete notes
- Count display (You have 0 notes)
- Persistence via localStorage
- Dark mode and responsive design

## How to run locally
1. git clone https://github.com/YOURUSERNAME/quicknotes.git
2. Open index.html in browser

## Files
index.html, style.css, script.js, README.md at root.
